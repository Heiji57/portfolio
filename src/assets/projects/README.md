# Project images & videos

프로젝트 이미지·영상을 `<slug>/` 폴더에 넣으면 자동으로 반영됩니다. (slug는 `src/data/projects.ts`의 `slug` 값)

```
src/assets/projects/
  chaekmaru/
    cover.webp   ← 본문 "Selected Work" 목록의 프로젝트 카드 이미지 + 상세 하단 "다음 프로젝트" 미리보기
    01.webp      ← 상세 갤러리 1번 슬라이드 (메인 화면)
    02.mp4       ← 2번 슬라이드 (핵심 기능) — 영상도 이미지처럼 번호만 맞추면 됩니다
    ...
```

- 지원 확장자: 이미지 png, jpg, jpeg, webp, avif, gif, svg / 영상 mp4, webm, mov, m4v
- 갤러리는 파일 이름 순(숫자 인식)으로 정렬되어 캡션과 순서대로 짝지어집니다.
- 갤러리 이미지 설명은 `src/data/projects.ts`에서 프로젝트별 `gallery`에 **파일 이름(확장자 제외)** 으로 적습니다. 없으면 설명 없이 `01 / 03`만 표시됩니다.
- 갤러리 슬라이드 수는 넣은 이미지 개수와 같습니다. 이미지가 하나도 없으면 갤러리 영역 자체가 숨겨집니다.
- `cover`가 없으면 목록 카드에는 스트라이프 placeholder가 표시됩니다.
- `cover`는 칸을 가득 채우고 넘치는 부분은 잘립니다(`object-cover`). 권장 비율 16:11.
- 갤러리 이미지는 잘리지 않고 전체가 보입니다(`object-contain`). 칸과 비율이 다르면 여백이 생깁니다. 권장 비율 16:10.

## 영상

- 영상은 소리 없이(muted) 반복 재생되며, 화면에 보일 때만 재생됩니다.
- `cover.mp4`처럼 cover로도 쓸 수 있습니다. 카드에서는 이미지와 똑같이 꽉 채워 보여 줍니다.
- 갤러리에서 영상 슬라이드는 이미지(4초)와 달리 **영상 길이만큼** 보여준 뒤 다음으로 넘어가고, 슬라이드가 나올 때마다 처음부터 재생됩니다.
- 용량이 크면 페이지가 느려지고 저장소도 커지니, 데모 영상은 10~30초, 몇 MB 이하(mp4/H.264 권장)로 줄여 넣어 주세요.

## 이미지 설명 (캡션)

```ts
// src/data/projects.ts
{
  slug: 'collabops',
  // ...
  gallery: {
    '01': { caption: '메인 화면', description: '문서 목록과 실시간 편집 화면입니다.' },
    '02': { caption: '권한 설정' }, // description은 생략 가능
  },
}
```

- 키는 파일 이름에서 확장자를 뺀 값입니다. `01.png`, `01.mp4` → `'01'`
- `caption`은 `01 / 03 — 메인 화면`처럼 번호 옆에 짧게, `description`은 그 아래에 문장으로 표시됩니다.
- 둘 다 선택 사항이고, 적지 않은 슬라이드는 번호만 표시됩니다.
